# Aslı Olan Düzen — Dijital Evren Arşivi

Alper Ulaç ALTAYLI'nın **Aslı Olan Düzen** adlı alternatif tarih romanı ve kurgusal evreni için hazırlanan resmî tanıtım sitesi.

## Yapı

- `index.html` — Ana sayfa
- `assets/css/style.css` — Görsel tasarım ve mobil uyumluluk
- `assets/js/main.js` — Mobil menü ve arayüz etkileşimleri
- `assets/images/favicon.svg` — Site simgesi
- `robots.txt` ve `sitemap.xml` — Arama motoru dosyaları

## Yerel görüntüleme

Depoyu bilgisayarına indirdikten sonra `index.html` dosyasını tarayıcıda açabilirsin. Harici bir derleme aracı gerekmez.

## GitHub Pages yayını

1. Repository içindeki **Settings → Pages** bölümünü aç.
2. **Build and deployment** altında kaynak olarak **Deploy from a branch** seç.
3. Branch: `main`; folder: `/(root)` seç.
4. **Save** düğmesine bas.
5. Yayın adresi: https://alperulacaltayli.github.io/asli-olan-duzen/

GitHub Pages etkinleştirildikten sonra ilk dağıtımın tamamlanması birkaç dakika sürebilir.

## Yayın ilkeleri

- Yalnızca kamuya açık olması onaylanmış eser ve evren bilgileri yayımlanır.
- Yayımlanmamış roman bölümleri, özel notlar ve gizli kanon belgeleri depoya eklenmez.
- Sitede anlatılan alternatif tarih ve evren unsurları kurmacadır.
- Okuma bağlantısı Inkitt üzerindeki eser sayfasına yönlendirir.

## Teknolojiler
