# Obsidian şablonları

Her Markdown şablonu başlangıçta status: taslak ve visibility: internal olarak gelir. Bu değerler değiştirilmeden siteye aktarılmaz.

Yayımlama için iki koşul birlikte gerekir:

status: onaylandı
visibility: public

JSON metadata şablonları doğrudan ilgili medya klasöründeki _metadata.json dosyasına uyarlanmalıdır.
